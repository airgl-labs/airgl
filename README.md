# [AirGL 4 VSCode] 

Computing on server. GUI on your devices. One-click.

Run heavy simulations on a remote GPU Server and interact seamlessly on your local devices.
On one click.

🌟 We’re the VSCode tool exactly you’re looking for…

* Executes simulations on a remote GPU Server
* Streams the GUI to your devices super-fast
* With no annoying setups, and just single-click
* Works on every environments(macOS, Windows, Linux, etc.)
* Easy Setup: Download and install the AirGL VSCode Extension from the Marketplace on both your client and remote environments.
* Simple Connection: Single-click and you can easily configure your remote server (IP, port, public key, etc.).
* Automatic Remote Compute: Simulations initiated within VSCode will automatically utilize the remote server's computational resources.
* Integrated Simulation Window: Visualize simulations directly within VSCode, providing a seamless and integrated user experience.
